Help & Controls


        

            
Keyboard Shortcuts

            
    
                
  • Ctrl+Z - Undo
    • 
                
  • Ctrl+Shift+Z - Redo
    • 
                
  • Ctrl+Arrow Left - Previous brush in history
    • 
                
  • Ctrl+Arrow Right - Next brush in history
    • 
                
  • Hold Space - Drag/pan around the canvas
    • 
                
  • Mouse Wheel - Pan up/down
    • 
                
  • Shift+Wheel - Pan left/right
    • 
                
  • Ctrl+Wheel - Zoom in/out
    • 
            

        


        

            
Tools

            
    
                
  • Brush - Paint with the selected palette item
    • 
                
  • Bucket - Fill connected area with current brush
    • 
                
  • Select - Select, move, copy, or delete areas
    • 
                
  • Mirror - Paint symmetrically on both sides
    • 
                
  • Zoom - Cycle through zoom levels (0.05x to 1x)
    • 
                
  • Fit - Auto-fit canvas to viewport and center
    • 
                
  • Animate - Create multi-frame animations
    • 
            

        


        

            
Select Sub-modes

            
    
                
  • Drag - Pan around the canvas (like holding space)
    • 
                
  • Select - Draw selection rectangles
    • 
                
  • Move - Move selected area to new position
    • 
                
  • Duplicate - Copy selected area to new position
    • 
                
  • Delete - Clear selected area
    • 
            

        


        

            
Modes

            
    
                
  • Grid Mode - Standard tile-based editing
    • 
                
  • Freeform (Beta) - Free placement of stamps anywhere
    • 
            

        


        

            
Size Presets

            
    
                
  • Discord - Default 4x7 grid
    • 
                
  • Discord Tall - 16x7 for taller images
    • 
                
  • I-Mode - 100x100 for large imports
    • 
                
  • G-Mode - 50x50 for quality GIF imports
    • 
                
  • Art - 32x32 for detailed art
    • 
            

        


        

            
Import/Export

            
    
                
  • Import - Load an image onto the grid
    • 
                
  • Gimport - Import GIF frames as animation
    • 
                
  • Save PNG - Export current frame as PNG
    • 
                
  • Save GIF - Export animation as GIF (Animate mode)
    • 
                
  • .binblock - Save/load full project files
    • 
            

        


        

            
Tips

            
    
                
  • Right-click palette items to favorite them
    • 
                
  • Use "Show favorites only" to filter the palette
    • 
                
  • Hide side panels for more canvas space
    • 
                
  • G-Mode import gives higher quality but larger files
    • 
            

        


        

            
        

    





    

        
BinBlockBuddy v3cb - Changelog


        

            
New in v3cb

            
    
                
  • GIMPORT (GIF import) reliability fixes - omggif fallback, safer frame decoding, and better error handling.
    • 
                
  • Smoother image and GIF imports with a "LOADING" overlay and clearer progress messages.
    • 
                
  • Renamed I-Mode to BIG IMAGE! (100x100) and G-Mode to IMAGE (50x50) to better match how they're used.
    • 
                
  • Performance tweaks for large grids, including skipping heavy export previews for very big canvases.
    • 
            

        


        

            
New in v3c

            
    
                
  • Added .binblock project filetype - save and load full BinBag projects.
    • 
                
  • Image importing into the grid for quick emoji layouts.
    • 
                
  • GIF importing (Gimport) to pull GIF frames into animation.
    • 
                
  • Image and GIF exporting from your current grid or animation.
    • 
                
  • Experimental Freeform mode for stamp-based painting off the strict grid.
    • 
                
  • Animation mode with multiple frames and GIF export support.
    • 
                
  • Ctrl+Arrow Left / Ctrl+Arrow Right to move back and forth through brush history.
    • 
                
  • New canvas size presets including I-Mode and G-Mode for imports.
    • 
                
  • Drag controls (space to pan, drag sub-mode) for easier navigation.
    • 
                
  • This changelog panel so you can see what changed.
    • 
            

        


        

            
Earlier Highlights

            
    
                
  • Panel hide/show tags for Palette and Export panels.
    • 
                
  • Zoom system for fitting very large canvases into the viewport.
    • 
                
  • Theme system and Settings panel for customizing colors.
    •
